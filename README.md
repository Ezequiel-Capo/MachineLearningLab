# MachineLearningLab

## Laboratorio 1: TorrAAca – Predicción Climática con Aprendizaje Automático

### Descripción

Este laboratorio tiene como objetivo aplicar técnicas de **aprendizaje automático supervisado** para predecir eventos climáticos en Uruguay, específicamente si un **día** o un **mes** será lluvioso, utilizando datos reales del **Instituto Nacional de Meteorología (INUMET)**.

El proyecto, denominado **TorrAAca**, combina:
- Preprocesamiento de datos.
- Ingeniería de atributos (fases de la luna, valores históricos, variables discretizadas).
- Implementación de clasificadores desde cero y con `scikit-learn`.
- Evaluación mediante validación cruzada, matrices de confusión y análisis de hiperparámetros.
